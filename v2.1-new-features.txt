Traveller World & System Generator — What's New in v2.1
=========================================================

SPECULATIVE TRADE CARGO GENERATION
------------------------------------
The generator can now produce a cargo manifest of available speculative trade
lots for any mainworld, following the Mongoose Traveller 2e Core Rulebook
pp.244-245.

Common goods (D66 11-16) — electronics, industrial goods, manufactured goods,
raw materials, consumables, and ore — are always listed at worlds with a
functioning starport. Trade goods (D66 21-56) appear only when the world has
a matching trade code. Worlds with Starport X have no cargo infrastructure
and return an empty manifest.

For each available lot the generator rolls:
- 1D (or more) for tonnage, multiplied by the lot's unit factor.
- 3D + the best purchase DM matching the world's trade codes, minus the best
  sale DM for those codes, minus Broker 2 (assumed supplier skill). The
  combined roll determines the purchase price as a percentage of the base
  price, ranging from 300% (on a very low roll) down to 15% (on a very high
  roll).

WEB APP — CARGO TAB
--------------------
After generating a Full system in the web interface, a Cargo button appears
in the seed/save bar. Clicking it calls the cargo endpoint with the current
seed and the mainworld's data, then displays the results in a new Cargo tab.
The tab lists every available lot with six columns: D66, Trade Good, Tons,
Base Cr, DM (purchase modifier), and Purchase Cr (actual price at this world
with this seed).

Results are deterministic — the same seed always produces the same manifest
for the same world. The Cargo button is disabled for basic (non-Full) system
generations, since no world JSON is available in that mode.

GEN-UI — CARGO WINDOW
-----------------------
The desktop app gains a Cargo button in both system mode and world-only mode.
Clicking it opens a Cargo window — a native table with D66, Trade Good, Tons,
Base Cr, DM, and Purchase Cr columns. Multiple cargo windows can be open at
once. Results are seeded from the current seed for reproducibility.

UNUSUAL STARS COLUMN AND POST-STELLAR REMNANTS
-----------------------------------------------
The generator now supports the Unusual Stars option from the Worlds Beyond the
Horizon supplement (WBH p.219). When this option is enabled, the primary star
can be a post-stellar remnant or exotic environment instead of a normal star.

Possible results include:
- White Dwarf (D) — dice-rolled mass, diameter, temperature, and luminosity.
- Neutron Star (NS) — dice-rolled mass and diameter; very hot and tiny.
- Pulsar (PSR) — a fast-rotating neutron star; all orbiting worlds are in a
  radiation zone.
- Black Hole (BH) — exploding-die mass roll; Schwarzschild diameter calculated
  from mass; no temperature or luminosity.
- Nebula, Star Cluster, Anomaly — exotic environments with a Giants-class host
  star and descriptive notes.
- Protostar — a pre-main-sequence star with full WBH p.219 physical rules
  (see Protostar Characterisation below).

When the primary is a dead star, the generator first checks whether a planetary
system survived the stellar death event. If it did, world counts are adjusted
downward — fewer gas giants, belts, and terrestrials than around a living star.

The Unusual Stars option appears as a checkbox in the web app (Orbital options
row) and in the gen-ui Options dialog. The setting is remembered across sessions.

FREIGHT LOT GENERATION
-----------------------
The generator can now calculate how much freight is available to ship at any
mainworld, following the Mongoose Traveller 2e Core Rulebook p.239.

Freight is divided into three tiers:
- Incidental lots (small: 1D tons each).
- Minor lots (medium: 1D×5 tons each).
- Major lots (large: 1D×10 tons each).

The number of lots in each tier is determined by a 2D roll modified by the
world's population, starport rating, tech level, and travel zone. Mail
(5 tons per container) may also appear on a high roll.

WEB APP — FREIGHT TAB
----------------------
After generating a Full system in the web interface, a Freight button appears
in the seed/save bar alongside the Cargo button. Clicking it calls the freight
endpoint with the current seed and the mainworld's data, then displays a
summary table in a new Freight tab. The table shows each tier (Incidental,
Minor, Major, and Mail if present) with the number of lots and total tonnage.

The button is disabled for basic (non-Full) system generations.

GEN-UI — FREIGHT WINDOW
-------------------------
The desktop app gains a Freight button in both system mode and world-only mode,
next to the Cargo button. Clicking it opens a Freight window — a compact table
with Tier, Lots, and Total Tons columns. Multiple freight windows can be open
at once.

PROTOSTAR CHARACTERISATION (WBH p.219)
--------------------------------------
When an Unusual Stars result produces a Protostar primary, the star is now
characterised using the full World Builder's Handbook rules rather than a
placeholder Giants-class star.

The protostar's spectral type and subtype are determined by a roll on the Star
Type table with DM+1, placing it on the main sequence (Class V). Its mass has
a ±50% random variance from the standard Class V value. Its diameter is the
Class V baseline multiplied by a random factor between 1.0 and 2.0, simulating
the bloated, still-contracting envelope of a young star. Luminosity is
recomputed from the modified diameter.

Any other stars in the system — close companions, wide companions — are also
generated as protostars following the same rules (WBH: "if the primary star is
a protostar, any other stars in the system are also protostars").

The Stars table in the system card now shows the correct spectral type (e.g.
"K5 V") rather than a Giant classification. The Peculiar environment note
("Peculiar environment: Protostar") remains visible in the Note column.

The age cap (< 0.01 Gyr) and the rule that no worlds exist in a protostar
system are unchanged.

BUG FIXES
---------

MULTI-STAR TIDAL STRESS DM NOW APPLIED CORRECTLY

Worlds in systems with multiple stars now receive the correct tidal stress
floor reduction. The World Builder's Handbook (pp.105-106) specifies that the
tidal stress floor for a world orbiting N stars should be reduced by N-1. This
DM was previously not applied. A world orbiting both a primary and one close
secondary star, for example, now receives a -1 floor reduction.
